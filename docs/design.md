**当前拍板（实现向）**

- 启动坞 = **钉宠锚点 + Appica 暖玻璃卡片**（非径向环、非系统 Acrylic）。  
- 菜单 / 设置 / 提醒叠层：CPU 自绘 + HiDPI 物理像素；开合对静帧卡层 scale+fade + hover/press 插值。  
- **观感目标**：点宠 → **卡片从身边长出**；宠不闪、不跳、不弹（宠始终全不透明、自由剪影，不套玻璃托盘）。  
- 点右上角肉垫印 → **设置从该印中心长出**并停靠坞旁。设置**只从启动坞进入**。  
- 开坞 / 设置转场呈现 **~60fps**；几何开局锁定；**关坞不把 HWND 缩回 128**（改尺寸会丢掉 layered 位图，宠闪）。  
- 列表：**视口约 5 行 + 滚轮滚动**（软上限 128，**不是**封顶 5 个）；其上固定「最近启用」图标条。  
- 文字：Windows **GDI 栅格**（hinted）；更精致字体渲染 **后期再做**。  
- 形象与飞扑精修放后期（见 `task.md` M6-D / PET-A07）。

## 1. 设计目标与原则

1. **轻量存在**：常驻但不吵；小而萌，低打扰。  
2. **状态可读**：用户一眼知道在待机、观察、提醒还是开了菜单。  
3. **动作即反馈**：点击 / 拖动 / 开坞 / 投喂 ≤100ms 内有反应。  
4. **同一世界**：宠、坞、提醒、设置共用色板与圆角气质。  
5. **成本可控**：自绘面板 + 精灵帧；不做重 shader / 实时桌面模糊。

## 2. 视觉系统

### 2.1 风格

- 画风：日系治愈 Q 版，圆润、大眼；奶牛猫黑白斑作桌面锚点。  
- 氛围：软萌、慵懒、偶发傲娇。  
- 面板：**Appica 级精致暖玻璃** — 近白暖 tint、soft 控件、深 slate 主按钮、粉 accent 点缀；宠物本体高对比黑白。  
- 参考气质：Appica UI（干净 token、分层阴影、scale+fade 微交互），**不**引入 Web 组件库。

### 2.2 色板（Tokens）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `pet.fur.base` | `#FFFFFF` | 身体白 |
| `pet.fur.spot` | `#2B2B2E` | 斑纹 |
| `pet.nose` | `#FFB6C1` | 鼻 / 肉垫 |
| `accent.pink` | `#FF9EC4` | 列表高亮、空状态点缀、选中条 |
| `accent.secondary` | `#8ED1D6` | 次强调 |
| `primary` | `#1E293B` | 启动坞主按钮（Appica 深 slate） |
| `primary.hover` | `#334155` | 主按钮悬停 |
| `primary.press` | `#0F172B` | 主按钮按下 |
| `surface.panel` | `#FFFBFA` @ ~92% | 玻璃面板底 |
| `surface.muted` | 浅暖灰半透明 | soft 行 / chip |
| `surface.hover` | 更亮半透明白 | hover 升亮 |
| `text.intense` | `#0F172B` | 标题 / 正文 |
| `text.muted` | slate 60–70% | 说明 |
| `text.onPrimary` | `#FFFFFF` | 主按钮字 |
| `border.subtle` | slate @ ~10% | 产品感描边 |
| `state.warning` | 橙底 + 深橙字 | 失效 |
| `state.danger` | `#E11D48` | 删除 |
| `shadow.elevated` | slate 低 alpha | 拎起行 / 设置卡；**坞卡本身无外阴影** |

深色主题：面板 `#2A2730` @ 类似透明度（首期可读系统主题一次；运行中可不实时跟随）。

### 2.3 圆角 · 间距 · 描边

| 用途 | 值（96 DPI） |
| --- | --- |
| 大面板 / 坞 | 18–20px |
| 按钮 / 行 | 10–12px |
| 小芯片 | 8–10px |
| 间距基准 | 8px；内边距 16px |
| 玻璃描边 | 1px subtle border + 顶部高光（裁进圆角轮廓，无内白 hairline） |

### 2.4 字体

- 实现：Windows **GDI** `CreateFontW` + `DrawTextW`（优先 **Microsoft YaHei UI**，Medium 字重，灰阶 AA + 对比度曲线）。  
- **不用** fontdue 画 UI 字（无 hinting → 拉丁波浪/大小不一）。  
- 档位：提醒 20 · 标题 17 · 正文 14–15 · 辅助 11–12。  
- 已知：整体略偏「发虚」可接受；**更精致字体（ClearType/子像素等）后期再改**。

### 2.5 缓动

| 名 | 曲线 | 用途 |
| --- | --- | --- |
| `ease.out_quint` | 五次缓出、**无 overshoot** | 开坞卡 scale 主曲线 |
| `ease.out_cubic` | 三次缓出 | 开坞卡 fade（略领先 scale） |
| `ease.snappy` | 微回弹 | 按下回弹、投喂成功 |
| `ease.smooth` | 减速 | 移动、边缘、stagger 子项 |
| `ease.out_back` | 轻回弹（保留） | 可选强调；**开坞已不用**（易弹跳感） |
| `approach` | 指数逼近 | hover / press 插值 |

实现：`src/render/easing.rs`（另含 `stagger_t` / `lerp`）。

## 3. 宠物形象与状态视觉

### 3.1 尺寸

- 设计窗逻辑基准：**128×128**（内容可小于框，留透明边）。  
- **显示尺寸** = 基准 × `pet.scale`（用户可调；默认 **0.6** ≈ 77 逻辑边长）。  
- 调节范围 **50%–100%**（上限不可再加），步进 **10%**；设置与托盘同一套钳位。HiDPI 下物理像素 = 逻辑 × DPR。  
- 精灵资源常见 **256×256** 帧，呈现时缩放到当前窗。  
- 锚点：着地点附近，切换 clip 不跳脚。

### 3.2 状态 → 视觉

| 用户感知 | 状态 | 视觉要点 |
| --- | --- | --- |
| 日常待机 | Idle base | **正面坐姿** + **真眨眼**（上眼皮遮虹膜）+ **头眼跟随**（不整图翻转） |
| 撒娇 | Idle one-shot | **`idle_yawn`**（峰值「困死我了…」）或 **`idle_stretch`**（紧凑左侧伸；峰值开心眯眼吐舌；无气泡） |
| 在看你 | Watching | 仍坐姿待机；头眼跟光标；不左右镜像 |
| 被拎起 | Dragging | 母版坐姿 + 轻微 scale 脉冲 |
| 躲边 | HiddenAtEdge | 母版坐姿半隐藏 |
| 催你起来 | Reminder | 正面轻跃到中央 → 卡片（tishi）+ 坐姿 → 投喂 → 轻跃回原位 |
| 开了工具 | MenuOpen | 坐姿待机，不抢坞 |

资源目录名与映射见 `tech.md` §3.2。

### 3.3 待机节奏（体验）

- 微生命感：真眨眼（可双眨）+ 头眼跟随；**身体钉在母版坐姿**，不靠整段视频换一只猫。  
- 约 **60s** 打一次哈欠或伸懒腰（轮播）；鼠标在旁边观察时不要饿死计时。  
- 调度：`IDLE_ACTION_ENABLED = ["idle_yawn", "idle_stretch"]`。旧 cute/sleep/wag/watch **已下盘**。  
- 哈欠：同一只正面猫；峰值奶油色墨线气泡「困死我了…」，默认出在头右侧。拖动 / 开坞可打断并回坐。  
- 伸懒腰：同一只猫紧凑左侧伸（转 → 下蹲 → 探 → 半峰 → 峰）；墨线与毛发质感跟母版；峰值开心眯眼吐舌。无气泡、不拓窗；进出与待机同一 letterbox。  
- oneshot 从坐姿书挡进，回 base 约 **100ms** 书挡（`go_idle_with_settle`）。  
- 打包哈欠：`python tools/pack_idle_yawn.py`（五官贴回 `idle_blink/000`，外轮廓不换）。  
- 打包伸懒腰：`python tools/pack_idle_stretch.py`（母版 5 键 + hold；1024 抠边；书挡 ≡ `idle_blink/000`）。  
- 呈现：宠体底对齐；哈欠扩窗时猫必须与待机同一 letterbox（同边距、同落点），只在旁边长气泡，**体型不能突然变大/变小**。不写 config 位置。  
- 抬头低头：`look_pitch` 从正面母版重画（0 低头 … 2 正面 … 4 抬头），不是旧抠图修边。

## 4. 桌面存在与基础交互

### 4.1 窗口

- 真透明、无标题栏、轻置顶。  
- 透明像素不挡桌面；实体可点。  
- 关窗 = 隐藏或忽略；**退出只在托盘**。

### 4.2 拖动

- 按下移动超过阈值才算拖（避免和单击开坞冲突）。  
- 拖动有缩放/晃动反馈；松手回待机。  
- 拖动优先于提醒流程打断。

### 4.3 边缘

- 靠近边缘 → 部分藏入，留探头。  
- 点探头或靠近恢复。  
- **开启动坞前**须先完全露出来（避免锚点在屏外）。

### 4.4 鼠标距离（体验）

| 距离感 | 行为 |
| --- | --- |
| 远 | 不理会 |
| 中 / 近 | **观察** |

需迟滞，避免边界来回抽风。

## 5. 快捷启动坞（Launcher）

### 5.1 体验目标

```text
看见猫 → 点一下 → 工具从身边长出 → 一点启动 → 收起
```

原则：一眼认、一步启、不打断桌面、**宠物是锚不是装饰**。

### 5.2 形态

- **玻璃卡片** + 宠物钉在屏幕原位附近。  
- 无系统标题栏；近白暖 tint 半透明 + 1px 粉描边 + 顶高光（裁进圆角）；**无外投影**（多层偏移圆角会在底/右边读成第二道线）。  
- **假磨砂即可**，不要系统 Acrylic / 抓屏模糊。  
- 卡片逻辑尺寸约 **360×450**（含「最近启用」与「应用列表」分区标题）；列表视口固定约 **5** 行，**滚轮滚动**查看更多（软上限 128，非产品封顶 5）。整窗 = 宠矩形 ∪ 卡片。  
- 宠物区：始终**自由剪影**（与待机像素对齐，不套玻璃托盘、无「轻点关闭」文案）；卡片 scale 绕宠心，宠矩形不参与 scale。

参考：`mockups/launcher-preview.html` · `launcher-pin-flip.*`。

### 5.3 空间布局（钉宠）

优先级：

```text
1. Flip   右空间不够 → 卡翻到左（再考虑上/下）
2. Shift  仍裁切 → 只滑卡片，尽量不动宠
3. Size   极少：略缩卡
4. 整体微移  仅兜底
```

目标：四边四角 **整卡在工作区内**；宠不「整卡硬推」式瞬移。

### 5.4 结构

| 区域 | 内容 |
| --- | --- |
| 标题 | 「给你叼来了」+「想开哪个？」；**右上角肉垫印**进设置 |
| 主按钮 | 「再叼一个」（**纯色实心** slate，无顶高光条、无底外阴影） |
| 常用条 | 「再叼一个」与列表之间；固定分区，标题「最近启用」+ 整宽圆角框；框内最多 **6** 个仅图标；按启动次数降序（并列取最近）；空框仍保留 |
| 列表 | 标题「应用列表」+ 应用行（图标圆点 + 名 + chevron）；**固定视口 + 滚轮**；**长按拖动排序** |
| 滚动提示 | 有更多时底部：「↓ 滚轮查看更多 · 共 N 个」 |
| 宠物区 | 钉死锚点；自由剪影，关坞靠点卡外 / 再点宠 |

空列表：引导去点「再叼一个」。

### 5.5 列表与异常

| 状态 | 表现 |
| --- | --- |
| 默认行 | 浅底半透明 |
| Hover | 更亮 / 略强阴影 |
| 按下 | 略深或粉感填充 |
| 失效 | 警告底；`!`；文案「无法找到程序 · 点此修复」 |
| 点失效 | 打开文件框原地换路径；不进设置 |
| 长按拖动 | 按住约 400ms 后拎起该行，列表让出插入缝；松手写入顺序 |
| 喂碗删除 | 长按拖动时猫咪下方出现空猫粮碗 +「喂给我删除」；丢进碗只删配置条目 |
| 数量 | 启用项全部进入列表（软上限 128）；视口约 **5** 行；`menu_list_scroll` + 滚轮 |
| 禁止 | 硬编码「最多 5 个就不能加」——产品上必须可扩展 |

### 5.6 开闭动画与微交互（Appica · 丝滑）

| 阶段 | 参数 |
| --- | --- |
| 时钟 | `menu_open_t` 为 **0..1 视觉量**（开 ~**180ms** / 关 ~**140ms**，ease-out 两端）；可从当前值反转 |
| 打开 scale | **0.95→1.0**，绕**宠心**生长，**无 overshoot** |
| 打开 fade | 时钟 ×1.22 封顶，**略领先** scale（先见材质再定形） |
| 阴影 | 坞卡**无**外投影；拎起行自带投影 |
| 宠物 | **始终全不透明**；不参与全局 alpha / 卡 scale；自由剪影 |
| 子项 | 跟卡一起 fade/scale；**无 stagger**（开合走静帧缓存，不能每帧重绘行） |
| 关闭 | 同一 scale/fade 映射，连续反转 |
| Hover | ~100ms `approach` 插值底色 / 阴影 |
| Press | scale **0.97** + translateY +1px；~80ms 入、松开回弹 |
| 布局 | **开局锁定 placement**，中途不二次 flip；hit-test 用**最终几何**（视觉偏移不改 hit） |
| 窗外点击 | 左键点在坞窗矩形外的桌面 / 其他窗口 → 关闭启动坞（`WH_MOUSE_LL` 观察型钩子，不吞点击） |
| 帧率 | 坞打开期间呈现 **~60fps**（见 tech §5 / §8） |

控件配方：

- **Primary**：深 slate 实心「再叼一个」+ 细描边（**禁止**厚顶高光 / 底阴影，否则像「两道影」）  
- **肉垫印**：标题右上 32px 命中区，进设置（参考奶油圆牌亮面四趾爪印 `assets/ui/settings_paw.png`）  
- **List row**：avatar 首字母 / `!`、hover 轻抬升、chevron  

**禁止（已踩过的坑）**

- 整窗（含宠）统一 `apply_rgba_alpha` → 宠先消失再淡入 = 闪。  
- 开坞用 `ease.out_back` → 弹跳割裂。  
- 先 resize 再等下一帧 redraw → 空帧闪。  
- 关坞把 HWND 缩回 128、下次开坞再放大 → **每次开坞都改 layered 窗尺寸**，位图被丢掉，DWM 偶发合成空帧 = 宠闪。正确做法：第一次开坞长大后**保持坞尺寸**，之后开/关只换位图。  
- 卡片高度不够 + `break` 裁行 → 只显示 2 个应用。  
- fontdue 小字拉丁 → 波浪/大小不一。  
- 弹系统文件框前把窗从 `AlwaysOnTop` 切到 `Normal` 再切回 → launcher **闪一下**。  
- 文件框打开 `%USERPROFILE%\Desktop` 文件系统路径 → 只见用户桌面，**公共桌面快捷方式缺失**。

业务：

- 启动成功 → 关坞动画。  
- **添加应用**：系统文件框打开期间 **坞保持**；launcher **不闪、不掉置顶**。  
- 文件框默认落在 Shell **虚拟桌面**（用户桌面 ∪ 公共桌面），可见桌面上全部 `.lnk` / `.url` / `.exe`。  
- 肉垫印 → 进设置：**从右上角肉垫印中心丝滑生长**，最终停靠在启动坞旁（锚点 + 工作区钳制）；启动坞卡层在转场前段同步淡出，避免硬切。设置只从启动坞进入。设置「暂停」不真停，猫咪身侧气泡 + 狡猾脸。  
- 关坞后 **~280ms** 防连环重开。

### 5.7 桌宠反馈（可选增强）

| 事件 | 文案方向 |
| --- | --- |
| 启动成功 | 「收到，马上打开～」 |
| 启动失败 | 「这个应用好像搬家了…」 |

首期可用日志 + 失效行代替气泡。

## 6. 健康提醒 UI

### 6.1 流程视觉

```text
原位坐姿 → 攒劲下蹲 → 正面轻跃（窗带弧线）→ 落地回坐
  → 提醒卡片（tishi.png 整图）→ 点击投喂
  → 再轻跃回原位 → 落地回坐待机
```

- 旅途 / 回程播 **`reminder_hop`**（母版漫画猫），不再用旧 `reminder_wave` 滑窗。朝向始终正面，不镜像。  
- 进度锁相：0–18% 原地攒劲（窗不动）→ 18–88% ease-in-out 抛物线飞行 → 88–100% 钉在终点回坐。  
- 时长随距离 550–1100ms；已在中央附近（&lt;56px）不跳，直接出卡。躲边先瞬间露全身再跳。  
- 落地书挡 ≡ `idle_blink/000`；旅途不拓窗、不换 letterbox。到位 / 投喂保持母版坐姿；卡片用 `tishi.png`（新猫）。

- 提醒窗口 **640×360（16:9）**：整图 `reminder_card.png`（猫举杯 + 漫画气泡两行文案）contain-fit 铺满窗口，不裁切、不叠框；杯子完整可见。

## 7. 设置与系统托盘

### 7.1 设置面板

- 打开方式：从启动坞右上角肉垫印点击时，**窗与猫钉死**，设置在原坞卡内从右侧滑入（220ms ease-in-out）；「完成」反转滑回启动坞。  
- 与启动坞同一套玻璃 / 圆角 / 字号气质。设置卡**无顶部内高光**（避免左上/右上圆角双线重影），只留一条圆角描边。  
- 分区顺序：  
  1. **健康提醒**（开关、间隔；「暂停」按钮保留但不生效）  
  2. **宠物大小**（`−` / 百分比 / `+`，相对设计基准；**50%–100%**）  
- 点「暂停」：宠位置不动，只换狡猾脸（`sly_pause`，同一坐姿身体）；身侧气泡「我没有这个功能，该喝水喝水，该活动活动」，约 2.8s。  
- 快捷方式不在设置里管理：添加走「再叼一个」，排序 / 删除走坞内长按拖动。  
- 关闭设置 ≠ 退出应用。  
- 调大小时：卡片屏幕位置**钉死**；开坞/进设置按 100% 体型预留叠层，宠按体型贴着卡片保持 `DEFAULT_GAP`，剪影（含尾巴）完整。「完成」提交尺寸并把待机原点钉在预览位置；Esc 丢预览、几何回进入时（画布保持预留，不缩窗）。托盘变大/变小与设置同一上下限，待机即时改窗。
