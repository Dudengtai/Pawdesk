PawDesk {VERSION}
Windows 桌面互动宠物：陪伴待机 + 快捷启动坞 + 健康提醒

【启动】
双击 pawdesk.exe。退出请用系统托盘菜单「退出」。

【常用操作】
- 单击猫咪：打开快捷启动坞
- 拖到屏幕边缘：半隐藏 / 探头
- 托盘：显示/隐藏、变大/变小、退出
- 启动坞右上角肉垫印：设置（提醒间隔、宠物大小）

【数据位置】
配置：%APPDATA%\PawDesk\config.json（启动坞应用列表、提醒、宠物位置）
日志：%LOCALAPPDATA%\PawDesk\logs\

安装包默认勾选「以出厂状态安装」，会清空上述配置，启动坞为未添加任何应用。
便携版沿用本机已有配置；若要恢复出厂，退出后删除 %APPDATA%\PawDesk 文件夹再启动。

请保持 assets\ 文件夹与 pawdesk.exe 在同一目录。
本目录可整夹拷贝使用（便携）。安装版请运行 PawDesk-Setup 安装包。
